# Michael's Coloring Club

A kids' coloring and badge game with 7 pictures: Rocket, Fish, House, Butterfly, Dino, Ice Cream and Hello Kitty.

The Hello Kitty page is a black-and-white version of a supplied picture (`hello-kitty-lineart.png`); its 15 colorable areas are traced into the page.

Play it at https://xniu3.github.io/michaels-coloring-club/
